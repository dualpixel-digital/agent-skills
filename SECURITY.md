# Política de segurança

Não registre segredos, dados pessoais, tokens, credenciais ou dados de clientes em issues públicas.

Para relatar uma vulnerabilidade nas instruções ou nos materiais deste repositório, envie uma descrição reproduzível para contato@dualpixel.com.br. Inclua o impacto, a skill afetada e uma forma segura de reproduzir o problema.

Não explore o problema em sistemas de terceiros e não publique detalhes antes de uma resposta da Dualpixel.
